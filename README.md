## 소개

문제를 깊이 이해하고, 가장 합리적인 해결책을 찾는 개발자 조승현입니다.

**문제 해결** 무선통신 연구실 학부연구생으로 활동하며 무선 통신 프로토콜의 성능을 개선하는 연구를 수행했고, 제1저자로 SCIE 및 KCI 논문을 게재하고 특허를 출원했습니다. 이 과정에서 복잡한 시스템의 문제를 정의하고, 가설을 세운 뒤 데이터를 통해 검증하는 방법을 익혔습니다.

**소프트웨어 개발** 홈서버와 서비스 인프라를 직접 구축하고 운영하며, 프로젝트의 기획부터 데이터 수집 및 가공, 개발, 배포까지 전 과정을 경험했습니다. 이를 통해 네트워크, 데이터베이스, 인프라가 연결된 전체 시스템을 바라보는 역량을 쌓았습니다.

**핵심 가치** 특정 기술이나 방식에 얽매이지 않고 문제의 본질을 충분히 이해한 뒤, 상황에 맞는 기술을 유연하게 선택하여 안정적이고 합리적인 해결책을 만드는 엔지니어를 지향합니다.
